# APPENDIX E: GLOSSARY

- **Agent Identity**: A unique cryptographic fingerprint locking the agent software to the physical hardware of the endpoint.
- **DPAPI (Data Protection API)**: A Windows cryptographic component used to locally encrypt sensitive configuration files.
- **Endpoint**: A remote Windows computer managed by the Sentinel platform.
- **Hexagonal Architecture**: A software design pattern that separates core business logic from external frameworks, improving modularity.
- **NSSM**: Non-Sucking Service Manager, a tool used to run the Python agent as a background Windows Service.
- **WMI**: Windows Management Instrumentation, the core Windows administrative framework used by the agent to query hardware and OS details.
