# ABSTRACT

Managing and monitoring a distributed fleet of endpoints remains a critical challenge for modern enterprises. **Endpoint Sentinel X** is an enterprise-grade Endpoint Monitoring and Management platform designed to bridge the gap between real-time telemetry collection and centralized administrative orchestration. 

Developed using a Hexagonal architecture, the system comprises a robust FastAPI backend, a high-performance Windows agent written in Python, and a responsive React frontend dashboard. The platform reliably collects hardware, network, operating system, and security telemetry, enforces real-time alerts (such as high memory utilization and unencrypted drives), and facilitates secure remote command orchestration.

This report details the complete software development lifecycle of Endpoint Sentinel X, from initial requirements analysis and architectural design through implementation, deployment on Render, and exhaustive testing. The results demonstrate a scalable, reliable, and secure platform capable of providing administrators with unparalleled visibility and control over their endpoint infrastructure.
