# Endpoint Sentinel X v1.0.0 - Production Demo Release

**Release Date:** August 2026

We are excited to announce the v1.0.0 Production Demo release of **Endpoint Sentinel X**, an Enterprise Endpoint Monitoring & Management Platform. This release marks the transition to a fully deployable, cloud-hosted architecture with a production-ready Windows Agent.

## 🚀 Major Features

*   **Role-Based Access Control & Authentication:** Secure JWT-based authentication with strict role assignments (Super Admin, Security Analyst, Operator, Viewer).
*   **Automated Endpoint Enrollment:** PowerShell-driven agent deployment scripts for seamless endpoint registration.
*   **Hardware & OS Inventory:** Automated collection of CPU, Memory, Disk, Network Interface specifications, OS versions, and installed applications.
*   **Performance Monitoring & Telemetry:** Continuous metrics collection and real-time streaming via WebSockets.
*   **Security Alerts & Posture Scoring:** Detection logic for suspicious behaviors and automated endpoint health calculations.
*   **Command Orchestration:** Execution of remote system commands directly from the dashboard.
*   **Enterprise Dashboard:** A highly responsive React dashboard utilizing modern design aesthetics.

## 🏗️ Architecture Summary

*   **Frontend:** React (v18), TypeScript, Vite, Tailwind CSS, TanStack Query.
*   **Backend:** FastAPI, SQLAlchemy (Async), Pydantic v2.
*   **Database:** PostgreSQL (Neon Serverless).
*   **Agent:** Windows Service packaged via PyInstaller, utilizing WMI and PowerShell collectors.
*   **Communication:** Dual-channel (REST for state, WebSockets for real-time telemetry).

## ☁️ Deployment Information

This release is fully optimized for modern cloud deployments:
*   **Frontend:** Hosted on Render as a Static Site.
*   **Backend:** Containerized via Docker and hosted on Azure App Service using GitHub Actions CI/CD pipelines.
*   **Database:** Hosted on Neon Postgres.

## 🔒 Security Features

*   Mathematical one-way password hashing (Argon2 / bcrypt).
*   Stateless JWT Authentication.
*   Strict Role-Based Access Control enforcing permission constraints on all backend routes.
*   Explicit Cross-Origin Resource Sharing (CORS) enforcement.

## ⚠️ Known Limitations

*   **Platform Support:** The endpoint agent currently only supports Windows Operating Systems.
*   **Demo Hibernation:** Cloud services (Azure/Render) may enter hibernation/sleep mode during periods of inactivity to conserve resources, which may cause a slight delay on initial boot.
